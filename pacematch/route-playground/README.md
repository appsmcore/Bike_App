# PaceMatch Route Playground

Fast Vite/Leaflet tester. Uses the **same keys and routing order** as the Flutter app.

## Setup

1. Put keys in **`../.env`** (pacematch root) — see `../.env.example`
2. Install & run:

```powershell
cd C:\Users\maxpi\Bike_App\pacematch\route-playground
npm install
npm run dev
```

Opens http://localhost:5173
